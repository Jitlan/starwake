# Starwake

An offline, touch-first vertical space shooter in the spirit of Tyrian. Everything (models, sound, UI) is generated in code in one HTML file, with Three.js inlined.

**Play:** https://jitlan.github.io/starwake/

To install on iPhone or iPad, open the link in Safari, tap Share, then **Add to Home Screen**. After the first launch it runs with no connection.
